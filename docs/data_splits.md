## 近似图复核

固定栏舍背景使dHash≤4产生大量候选。若同时把每10个连续编号作为组并合并所有近似候选，1015张图会连成一组，不能据此构造三个独立集合。因此未把该启发式当作已确认的来源关系，也未据此删除数据。

当前跨集合dHash候选图对：训练/验证3对，训练/测试37对，验证/测试10对，共50对；这些只是相似候选，不是确认重复。其示例与距离保存在检测` splits.json`的`similarity_review`中，供复核。字节完全相同的跨集合图片组为0。

在未确认这些候选、图片真实来源和检测/MOT视频重叠前，不应把v1上的结果表述为已验证的独立来源泛化性能。该限制不会因清单生成而自动消失。

## 使用与复现

总入口：`datasets/splits/initial_v1/manifest.json`。`configs/data.json`已指向本版本。

```bash
python -B scripts/create_initial_splits.py --output datasets/splits/initial_v2
```

数据及规则不变时可复现同样的成员分配；输出目录必须是新目录。图像来源查明后应改用真实来源分组流程，并保留版本对照。坐标转换、标注修复及训练仍未运行。
