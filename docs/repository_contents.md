# 仓库内容范围

本仓库用于保存猪只检测与多目标跟踪的实验代码和复现依据。

| 内容 | Git中是否包含 |
|---|---|
| README、依赖、模型适配、配置、数据处理和实验脚本、测试 | 包含 |
| protocol_v2的JSON、CSV、TXT划分记录 | 包含 |
| 原始文件的路径、大小、mtime及SHA-256清单 | 包含，仅元数据 |
| 六检测及六跟踪的正式结果、逐视频结果、调参表、冻结参数、结果图 | 包含精选快照 |
| 原始图片、XML、视频、逐帧GT及派生标签 | 不包含 |
| 模型权重、检测缓存、完整预测、运行日志、压缩备份 | 不包含 |
| Word周报、实验报告、内部交接与服务器连接记录 | 不包含，继续保存在本地 |
| 第三方源码副本 | 不包含，通过固定提交获取 |

实际本地项目可以同时保存上述所有内容；Git忽略规则控制上传范围，无需搬动原始数据或Word文档。

`datasets/raw/inventory.json`的基线建立于此前1001张无同名XML图片按要求删除之后，仅核验当前2051个原始文件，不能还原或证明删除前的数据状态。

本仓库是原论文方法的适配比较，不将上游算法描述为本项目原创；第三方代码与权重各自的来源见[第三方来源](third_party.md)。
