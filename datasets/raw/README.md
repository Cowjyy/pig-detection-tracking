# 原始数据来源登记

两个原始数据源保留在项目根目录，通过项目相对路径引用，不复制、不移动、不建立会误导写入位置的软链接。

| 用途 | 路径 |
|---|---|
| 检测图片 | `pig-objection detection/data/` |
| 检测原始 VOC 标注 | `pig-objection detection/label/` |
| 跟踪视频 | `PIG_MOT_TEST_DATA/MyVideo_<序列>.mp4` |
| 跟踪原始 MOT 标注 | `PIG_MOT_TEST_DATA/<序列>/gt/gt.txt` |

原始目录仅作读取来源。输出脚本拒绝将输出目录放到这些数据源中，且拒绝覆盖已有输出目录。未修改文件系统权限。

后续清洗、转换和划分只通过Python生成派生文件。任何GT修订均须保留原文件，并输出行级变更记录。
